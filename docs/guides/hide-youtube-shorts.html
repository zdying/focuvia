How to hide YouTube Shorts on desktop and mobile

Updated November 18, 2026

To hide Shorts on desktop, use a browser extension that supports your browser and YouTube’s current layout. In the YouTube mobile app, browser extensions do not apply; device app timers can limit usage instead. Hiding Shorts elements is different from blocking every way to access Shorts.

Focuvia is in development. There are no public store installation links yet; developer packages are available from GitHub prereleases. Desktop packages target Chrome/Edge 120+ and Firefox 142+ on www.youtube.com. Firefox development installation is temporary until signing is complete.

Desktop setup · iPhone and Android · Hiding vs. blocking · Troubleshooting

Desktop: Focuvia developer preview setup

  1. Check availability first. Visit the Focuvia release section. Download and extract the matching developer package. Chrome and Edge use Load unpacked; Firefox uses Load Temporary Add-on. Follow the browser-specific installation steps. Store installation is not available yet.
  2. Review permissions and install. The current build requests storage, desktop YouTube access and access to the Return YouTube Dislike API. See the privacy details before enabling it.
  3. Review the popup settings. In the current build, Hide Shorts, Hide recommendations and Hide comments default to on. Hiding the homepage feed is a separate option and defaults to off.
  4. Decide whether to show dislike estimates. They are on by default and send the current video ID to a third-party service. Turn “Show estimated dislike count” off if you do not want these requests.
  5. Check the YouTube pages you use. Recognized Shorts cards, shelves and navigation entries should be hidden when Hide Shorts is enabled. Regular video search results remain, but recognized Shorts results are hidden too. Check the homepage, search and watch page separately.

The current daily watch budget defaults to 30 minutes. Visible playback contributes to the budget, while pauses, seeking and buffering do not. Playback pauses at the allowance; you can add time or change the limit. Setting the limit to zero disables blocking.

iPhone and Android: app limits and browser alternatives

Focuvia does not run inside the YouTube app. Its current URL matching also excludes m.youtube.com, so installing a desktop extension is not a supported Focuvia mobile setup.

For total app-time limits, use Apple Screen Time app limits on iPhone or Android Digital Wellbeing app timers where supported. These limit the app rather than selectively removing Shorts. Menus and available controls vary by device.

If you prefer watching in a mobile browser, check both browser and extension support. For example, Unhook’s publisher listing describes mobile YouTube support through Firefox on Android, and UnTrap’s official site describes supported browsers including Safari on iPhone and iPad. Those are publisher statements, not Focuvia compatibility claims or a hands-on test.

Hiding Shorts vs. blocking Shorts access

Focuvia changes the display of recognized page elements. It does not act as a network filter, stop you opening a Shorts URL, prevent disabling the extension, or enforce a restriction in other browsers and apps. The current styles can also hide the Shorts player on recognized pages, but that is still display hiding rather than URL blocking.

YouTube can change its markup or roll out different layouts to different accounts. No extension should be assumed to hide every future layout permanently. Use YouTube’s own recommendation controls where available, and check results on the pages you actually use.

If Shorts still appear

  1. Confirm you are on www.youtube.com in a supported desktop browser, with the extension enabled and allowed to access the site.
  2. Open the popup and check Hide Shorts. Hiding the homepage feed or recommendations is a separate setting.
  3. Reload YouTube after changing extension permissions or installing an update. Compare a homepage shelf, a search result and a watch-page sidebar rather than assuming one check covers all layouts.
  4. If one layout remains visible, note the browser version, extension version and affected page type for a bug report. Avoid sharing private watch history or account information.

Focuvia behavior above was checked against development build 0.2.2 source. External references were reviewed November 18, 2026; availability can change.
