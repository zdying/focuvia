Focuvia privacy and data flows

Updated November 18, 2026

This notice describes Focuvia development build 0.2.3. Public store installation is not available yet. The current build has no Focuvia account system, analytics or Focuvia-operated backend.

Settings may sync through your browser

Feature preferences and the daily watch limit use browser sync storage (chrome.storage.sync). Depending on your browser and account settings, the browser provider may sync these settings across devices. This is not exclusively on-device storage. Focuvia does not require a separate account.

Watch totals stay on this device

Daily viewing totals, extra time and stopped state use chrome.storage.local. They are shared between the extension’s tabs on this device and are not sent to a Focuvia server. They are stored by day; starting a new day does not automatically delete previous daily records. The extension does not store a list of watched video IDs in these daily records.

Estimated dislike counts use a third-party service

The “Show estimated dislike count” option is enabled by default in the current build. On a YouTube video watch page, it sends the current video ID to https://returnyoutubedislikeapi.com/votes. Like other direct network requests, this also exposes connection information, including your IP address, to that service. Counts are estimates, not official YouTube dislike totals.

Turn this option off in the extension popup to cancel an active request, remove the displayed count and stop further dislike requests while it remains disabled. Disabling it cannot retract a request already received. Data handling by the third-party service is outside Focuvia’s control; see Return YouTube Dislike’s FAQ.

Permissions

The current manifest requests storage and access to www.youtube.com and returnyoutubedislikeapi.com. YouTube access is used to hide elements and measure playback for your watch budget. API access is used for estimated dislike counts. The current build does not request access to all websites or modify the YouTube mobile app.

Your controls

You can change the hiding options, disable estimated dislike counts, set the watch limit to zero to disable blocking, or remove the extension through your browser’s extension manager. Browser sync and synced-data deletion are managed through your browser provider; do not assume uninstalling on one device deletes every synced copy.

This website

The landing page loads fonts from Google Fonts, which involves requests to Google. It has no analytics scripts, account forms or cookie-setting code in its source. This website is hosted on GitHub Pages. GitHub logs and stores visitor IP addresses for security purposes; see GitHub Pages data collection and the GitHub Privacy Statement.
